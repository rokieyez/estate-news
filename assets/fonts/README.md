# 카드뉴스용 서체

카드뉴스(`images.cards`)에만 씁니다. 블로그 인포그래픽은 그대로 시스템 글꼴(`images.FONT`)을
씁니다 — 러너에 프리텐다드가 없어 그쪽까지 바꾸면 맥에서 만든 그림과 러너에서 만든 그림이
달라집니다.

| 파일 | 쓰는 곳 |
| --- | --- |
| `Pretendard-Bold.otf` | 제목·소제목 (굵게) |
| `Pretendard-Regular.otf` | 본문·설명·머리글 |
| `IBMPlexMono-Bold.ttf` | 큰 숫자 (29.5%, 162만원) |
| `IBMPlexMono-Regular.ttf` | 계측 표식 (`02 / 07`, 날짜, 색인) |

숫자에 고정폭을 고른 이유는 제도 도면의 판독값처럼 읽히기 때문입니다. 다만 고정폭은
글자마다 같은 너비를 차지해 큰 크기에서 헐거워 보이므로, 큰 숫자에는 음수 자간을 줍니다.

## 쓴 글자만 잘라 심습니다

**SVG 안에 base64 로 심어 보냅니다.** 깃허브 러너에는 이 글꼴이 없고, 크롬은 다른 로컬
파일을 기본적으로 못 읽기 때문입니다. 심은 SVG 는 PNG 로 바꾼 뒤 지워지므로(`keep_svg: false`)
저장소에는 쌓이지 않습니다.

**통째로 심으면 안 됩니다.** 프리텐다드 한 벌이 1.5MB 라 두 굵기를 그대로 넣으면 카드
한 장의 SVG 가 4MB 를 넘습니다. `fontTools` 로 그 카드에 실제로 쓴 글자만 잘라내면
네 벌을 합쳐 **20~30KB** 로 줄어듭니다(2026-09-08 실측: 23KB).

`fontTools` 가 없으면 조용히 시스템 글꼴로 갑니다 — 글씨가 조금 달라질 뿐 카드는 그대로
나옵니다. 러너에 `fonts-noto-cjk` 를 까는 단계를 남겨 둔 이유도 그 대비입니다.
