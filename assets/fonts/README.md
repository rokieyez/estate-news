# 카드뉴스용 라틴 서체

카드뉴스(`images.cards`)의 **숫자와 기호**에만 씁니다. 한글 본문은 시스템 글꼴
(Apple SD Gothic Neo / Noto Sans CJK KR)을 그대로 씁니다 — 이 두 서체에는 한글이 없습니다.

| 파일 | 쓰는 곳 |
| --- | --- |
| `BigShoulders-Bold.ttf` | 큰 숫자 (29.5%, 162만원). 좁고 높은 골격이라 큰 크기에서 형태가 산다 |
| `GeistMono-Regular.ttf` | 계측 표식 (`02 / 07`, 날짜, 색인). 고정폭이라 눈금처럼 읽힌다 |

**SVG 안에 base64 로 심어 보냅니다.** 깃허브 러너에는 이 글꼴이 없고, 크롬은 다른 로컬
파일을 기본적으로 못 읽기 때문입니다. 심은 SVG 는 PNG 로 바꾼 뒤 지워지므로(`keep_svg: false`)
저장소에는 쌓이지 않습니다.

둘 다 SIL Open Font License 1.1 입니다. 라이선스 전문을 `*-OFL.txt` 로 함께 둡니다 —
OFL 은 재배포할 때 라이선스를 같이 두라고 요구합니다.
