# 카드뉴스용 라틴 서체

카드뉴스(`images.cards`)의 **숫자와 기호**에만 씁니다. 한글은 시스템 글꼴을 그대로 씁니다
(맥은 Apple SD Gothic Neo, 러너는 워크플로가 까는 Noto Sans CJK KR) — 이 서체에는 한글이 없습니다.

| 파일 | 쓰는 곳 |
| --- | --- |
| `IBMPlexMono-Bold.ttf` | 큰 숫자 (29.5%, 162만원) |
| `IBMPlexMono-Regular.ttf` | 계측 표식 (`02 / 07`, 날짜, 색인) |

고정폭을 고른 이유는 제도 도면의 판독값처럼 읽히기 때문입니다. 다만 고정폭은 글자마다
같은 너비를 차지해 큰 크기에서 헐거워 보이므로, 큰 숫자에는 음수 자간을 줍니다.

**SVG 안에 base64 로 심어 보냅니다.** 깃허브 러너에는 이 글꼴이 없고, 크롬은 다른 로컬
파일을 기본적으로 못 읽기 때문입니다. 심은 SVG 는 PNG 로 바꾼 뒤 지워지므로(`keep_svg: false`)
저장소에는 쌓이지 않습니다.

**한글 서체는 심지 않습니다.** 시안에서는 Pretendard 로 그렸지만 파일이 6.7MB 라
카드마다 심으면 하루 60MB 를 헛되이 만듭니다. 부분집합을 뜨려면 fontTools 의존이
생기는데, 청사진의 성격은 격자·청록·고정폭 숫자에서 나오지 한글 서체에서 나오지
않으므로 그만한 값을 치를 이유가 없습니다.
