# 내 컴퓨터에서 쓰기

지금은 웹(claude.ai/code)으로 작업하고 계십니다. 이걸 내 컴퓨터로 옮기면
바탕화면의 지식 저장고(`project/CLAUDE.md`)까지 같이 읽히게 됩니다.

**매일 아침 자동 실행은 깃허브가 하므로, 옮겨도 그대로 돌아갑니다.**
컴퓨터를 꺼두셔도 글은 계속 만들어집니다.

---

## 1단계 · 앱 설치

본인 컴퓨터에 맞는 것을 받으세요.

- **맥** → [macOS용 내려받기](https://claude.ai/api/desktop/darwin/universal/dmg/latest/redirect)
- **윈도우** → [Windows용 내려받기](https://claude.ai/api/desktop/win32/x64/setup/latest/redirect)

받은 파일을 실행해 설치합니다.

## 2단계 · (윈도우만) Git 설치

**맥은 건너뛰세요.** 대부분의 맥에는 이미 들어 있습니다.

윈도우는 [Git for Windows](https://git-scm.com/downloads/win) 를 먼저 설치해야 합니다.
설치 화면은 계속 **Next** 를 눌러 기본값으로 진행하면 됩니다.
설치가 끝나면 **Claude 앱을 껐다가 다시 켜세요.**

이걸 안 하면 4단계에서 폴더를 골라도 동작하지 않습니다.

## 3단계 · 로그인하고 Code 탭 열기

1. Claude 앱을 실행합니다 (맥은 응용 프로그램, 윈도우는 시작 메뉴)
2. 평소 쓰시던 계정으로 로그인합니다
3. 화면 위쪽 가운데의 **Code** 탭을 누릅니다

> 탭이 **Chat / Cowork / Code** 세 개 있습니다. 우리가 쓸 것은 **Code** 입니다.

## 4단계 · 저장고 폴더 고르기

1. **Local** 을 고릅니다 (Cloud 아님)
2. **Select folder** 를 누릅니다
3. **바탕화면 → project** 폴더를 고릅니다

> 여기서 `project/estate-news` 가 아니라 **`project` 자체**를 고르는 게 중요합니다.
> 아직 프로젝트를 안 받았으니, 받을 자리를 먼저 열어 주는 겁니다.

## 5단계 · 프로젝트 받아오기

입력창에 이렇게 적고 보내세요.

```
active 폴더 안에 estate-news 저장소를 받아줘.
https://github.com/rokieyez/estate-news
```

받아오는 데 1분쯤 걸립니다. 끝나면 이렇게 됩니다.

```
바탕화면/project/
├─ CLAUDE.md          ← 지식 저장고
├─ active/
│  └─ estate-news/    ← 방금 받은 것
└─ inactive/
```

## 6단계 · 프로젝트 폴더로 다시 열기

받아온 뒤에는 **그 폴더에서** 작업하는 게 좋습니다.

1. 새 세션을 만듭니다 (맥 `Cmd+N`, 윈도우 `Ctrl+N`)
2. **Select folder** → **project → active → estate-news** 를 고릅니다

이제 이 순서로 읽힙니다.

| 순서 | 파일 |
| --- | --- |
| 1 | `project/CLAUDE.md` — 지식 저장고 |
| 2 | `project/active/estate-news/CLAUDE.md` — 이 프로젝트 전용 |

제대로 됐는지 확인하려면 그냥 물어보세요. **"내 지식 저장고 읽었어?"**

---

## 앞으로 기억하실 것 하나

매일 아침 7시에 깃허브의 로봇이 새 글을 저장소에 올립니다.
그래서 **컴퓨터에 있는 사본은 하루만 지나도 옛날 것**이 됩니다.

컴퓨터에서 작업 시작하실 때 저한테 이 한마디만 해주세요.

```
최신으로 받아줘
```

그러면 알아서 맞춰 놓습니다. 이것만 기억하시면 됩니다.

---

## 잘 안 될 때

**Code 탭을 눌렀는데 결제하라고 나옵니다**
Claude Code 는 유료 요금제(Pro, Max, Team, Enterprise)가 필요합니다.
웹에서 쓰고 계시다면 이미 있는 것이니, 로그인 계정이 같은지 확인해 보세요.

**폴더를 골랐는데 아무 반응이 없습니다 (윈도우)**
2단계의 Git 설치를 건너뛰셨거나, 설치 후 앱을 다시 켜지 않으신 경우입니다.

**웹이랑 컴퓨터 중 뭘 써야 하나요**
둘 다 쓰셔도 됩니다. 같은 깃허브 저장소를 보니까요.
- 휴대폰·외출 중 → 웹
- 지식 저장고까지 같이 쓰고 싶을 때 → 컴퓨터
